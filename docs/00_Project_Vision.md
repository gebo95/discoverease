# Core User Journey

Every major feature in DiscoverEase supports this journey:

**Discover → Save → Plan → Experience**

### Discover

Browse destinations, events, restaurants, beaches, tours, nightlife, and attractions.

### Save

Save experiences into organized lists for future trips or inspiration.

### Plan

Turn saved experiences into a trip with an easy-to-build itinerary.

### Experience

Use DiscoverEase during the trip to find live updates, navigate, and enjoy the destination.

---

# Version 1 Goals

By launch, a user should be able to:

- Browse a destination
- Search for experiences
- Explore by category
- View detailed listings
- Save experiences
- Create and manage trips
- Add experiences to trip days
- Receive business Pulse updates
- Discover nearby recommendations
- Contact businesses
- Visit business websites
- View menus, schedules, and important information
- Build an itinerary naturally

Businesses should be able to:

- Create and manage listings
- Upload photos
- Edit business information
- Post Pulse updates
- View basic analytics
- Subscribe to business plans
- Purchase additional Pulse posts if needed
- Apply for Featured placement

## Pulse

Pulse is communication—not advertising.

Businesses use Pulse to keep visitors informed.

Examples:

- Live music tonight
- Happy hour
- Closed today
- Special event
- Limited menu
- Weather update

Pulse should always provide value to the user.
