# Listing Detail V1

The detail page is photo-led and keeps the key decision facts near the top:
rating, review count, price, location, category, and destination. It then shows
the experience description, traveler tips, practical listing facts, and curated
Pair It With / Continue Your Day suggestions when those records exist.

Save and Add to Trip are connected to the current in-app repositories. Saved
items and planned experiences are held in memory for the current app session;
durable user accounts and storage belong to the Firebase backend milestone.
Contact, social, reservation-provider, opening-hours, directions, and map
controls are omitted until listings have verified data and the relevant service
is integrated. Pulse text shown on this page is the listing's current local
content field, not a live business feed.

Traveler Tips appear independently of recommendation availability. Empty
optional sections are not rendered. The sticky footer offers Save and Add to
Trip on every listing detail page.
